# PakposRides

A fuel-and-oil recommendation guide for Indonesian motorcycle owners. PakposRides maps each bike's compression ratio to an ideal fuel octane (RON) and engine oil, recommends fuel and oil brands for daily versus touring use, and estimates full-tank refuel cost from current per-litre prices.

**Live:** https://pakpos-rides.vercel.app

## Tech stack

| Layer | Choice |
|---|---|
| Framework | Next.js (App Router) + TypeScript |
| Styling | Tailwind CSS |
| Database & Auth | Supabase (PostgreSQL + RLS + Auth) |
| CDN | ImageKit |
| Maps & AI | Google Maps Services, Google Generative AI |
| UI | Lucide React, Framer Motion |
| Hosting | Vercel |
